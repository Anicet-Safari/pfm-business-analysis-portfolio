# Business Process Maps — Budgeting, Expenditure and Revenue

*Author: Anicet Safari, CPA · Illustrative work sample, October 2026*

Three end-to-end processes for a central-government entity, each mapped with swimlanes, step descriptions, the controls applied at each step and the system events the IFMIS records. Diagrams are written in Mermaid so they render directly on GitHub and stay editable as text.

| File | Process | Scope |
|---|---|---|
| [`budget_execution.md`](budget_execution.md) | Budget execution | From approved appropriation to budget release, reallocation and monitoring |
| [`commitment_to_payment.md`](commitment_to_payment.md) | Expenditure workflow | From purchase requisition to payment and posting |
| [`revenue_receipting.md`](revenue_receipting.md) | Revenue workflow | From assessment / invoice to receipt, classification and bank reconciliation |

Every control point carries an ID (for example `C-04`) that matches the controls matrix in folder 06.
